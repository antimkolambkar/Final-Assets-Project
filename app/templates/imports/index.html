Import Tips & Best Practices
  • Download the CSV template first to see the correct column format
  • Column headers are case-insensitive — spaces auto-normalized
  • Excel (.xlsx) and CSV files are both fully supported
  • For assets: include Vendor Name matching exactly what's in the system
  • Employee emails must be unique across the directory
  • Existing Employee IDs will be updated, not duplicated
  • The import audit log records all bulk operations with timestamps
  • Run Entra ID Sync after import to align statuses with Azure
